# 图标第二轮设计

用户否定了第一轮双弧抽象标志，选定「翻页＋日期标记」方向，并在三案中选择 C 课程卡片。随后要求统一内部对齐、所有圆角、两页间距、内容内边距与元素间距。当前母版从基础 token 推导这些关系。

- `comparison.svg/png`：初选三案的历史比较图，其中 C 为精修前版本。
- `turning-page.svg/png`：A 翻页日历，未选择。
- `course-book.svg/png`：B 课程书页，未选择。
- `course-stack.svg/png`：当前精修 C 的母版。
- `alignment.svg/png`：当前 C 的净稿与对齐结构。

正式使用的透明矢量文件在上级 `Brand/`。坐标、变体与使用说明见 [Brand/README.md](../README.md)。比较图中的文字不是 logo 的组成部分。
