# Syllapace 标志

当前标志采用课程卡片方向：叠放的课程资料、日期格与正在翻起的页角。青绿色表示当前页面，暖杏色用于后页、今日标记和翻角，让“课程与日程”的含义更直观。

Codex、Slack 和 Linear 是用户提供的精确、简洁风格参考；图形为本项目自绘，未使用这些品牌的图形资产、SF Symbols 或字体字形。

四个 SVG 使用相同的几何路径与日期圆点，仅填充颜色不同。页面中的标题、日期格及圆形留白使用 `evenodd` 复合路径，单色版本仍保留结构。文件不嵌入位图，不使用字体、滤镜、描边或外部资源。

## 圆角、对齐与留白

母版为 1024 × 1024，基础单位 `U=8`，结构间距 `G=4U=32`。几何由 [make_brand.py](../tools/make_brand.py) 统一生成；[geometry.json](geometry.json) 保存输入、推导尺寸与检查结果。尺寸一致指同类关系使用相同规则，外轮廓、内容与细小接点按层级使用不同圆角。

| 部分 | 几何约束 |
| --- | --- |
| 圆角层级 | 纸张外角 `R32`；标题和日期格 `R16`；翻角与缺口端点 `R8`，全部为圆弧相切连接 |
| 两页关系 | 后页向左、向上各偏移 96；顶部和左侧露出宽度均为 64，负形缝均为 32 |
| 两页转弯处 | 前页外角 `R32` 与后页内弧 `R64` 同心，弯曲处仍保留 32 间距 |
| 内容内边距 | 主页面外接矩形至内容外接矩形，上、下、左、右均为 `3G=96` |
| 日期格 | 外接框均为 `4G=128` 的正方形；横纵间距均为 `2G=64`，中心步长均为 192 |
| 标题横条 | 高 32、宽 320，与日期阵列左右齐边；标题至第一排日期格的间距为 64 |
| 当前日期 | 外圈 `R64`，内圆 `R32`；负形环宽 32，与结构间距一致 |
| 翻角缝隙 | 翻角 `R96` 与页面缺口 `R128` 共用圆心 (816,864)，主体弧线间距为 32；端点用 `R8` 相切圆接，端头处间隙自然展开 |
| 翻角避让 | 当前日期圆与页面缺口之间最短距离约 34.27，大于最小结构间距 32 |

内容的 96 内边距以主页面完整外接矩形为基准；翻角是这个矩形局部裁去的部分，另以最短距离检查避让。这里没有将裁切弧误称为等距内容边沿。

交付 SVG 使用 `viewBox="128 128 768 768"`。整体图形范围为 x=208…816、y=160…864，中心为 (512,512)，取景净空左右各 80、上下各 32。两页保留纵向纸张比例。原生应用图标将这一完整构图围绕中心等比缩放到 560 单位高，不分别移动内部元素。

[结构图](concepts-v2/alignment.svg) 展示净稿、间距与翻角细节。建议至少以 24 px 显示完整日期细节；16 px 主要保留叠页轮廓，不承诺全部小间隙仍可逐一辨识。复杂背景可在现有净空之外继续增加留白。

修改 `Brand/geometry.json` 的基础 token 后运行 `python3 tools/make_brand.py --render`，重新生成透明 SVG、原生图标分层、几何记录和 PNG 预览。生成器检查相切、避让和间距关系，不满足约束时报告失败；`--check` 只检查已提交产物是否与参数一致。PNG 渲染使用 `rsvg-convert`；编译应用图标另运行 `./tools/make_icon.sh`。结构标注图单独维护，改变尺寸后需同步更新。

## 应用图标

分层源位于 [Icon/AppIcon.icon](../Icon/AppIcon.icon)。原生图标与此矢量母版使用同一页面和日期几何；材质、系统圆角与外观适配由 Icon Composer / macOS 生成。独立 SVG 本身不含这些系统效果。

[课程卡片母版](concepts-v2/course-stack.svg) 保留完整 1024 坐标，便于继续对齐检查与编辑。
