# Syllapace 标志

当前标志采用课程卡片方向：叠放的课程资料、日期格与正在翻起的页角。青绿色表示当前页面，暖杏色用于后页、今日标记和翻角，让“课程与日程”的含义更直观。

Codex、Slack 和 Linear 是用户提供的精确、简洁风格参考；图形为本项目自绘，未使用这些品牌的图形资产、SF Symbols 或字体字形。

四个 SVG 使用相同的几何路径与日期圆点，仅填充颜色不同。页面中的标题、日期格及圆形留白使用 `evenodd` 复合路径，单色版本仍保留结构。文件不嵌入位图，不使用字体、滤镜、描边或外部资源。

## 对齐与留白

母版使用 1024 单位坐标。交付版本的 `viewBox="160 160 704 704"` 将页面构图居中取景；图形横向范围为 224–800，纵向范围为 208–816，因此左右净空各 64 单位，上下各 48 单位。

| 部分 | 几何约束 |
| --- | --- |
| 日期格 | 每格外接框均为 96 × 96；方格圆角为 16 |
| 两行、两列 | 中心坐标分别为 480、640；中心步长均为 160 |
| 格间距 | 相邻格外接框间距均为 64 |
| 标题横条 | x=432…688，宽 256，与日期格整体左右外缘对齐；y=352…384，高 32 |
| 当前日期 | 外圈半径 48，与同排同列格子的外接框一致；内圆半径 24，留下 24 单位负形环 |
| 主页面 | x=320…800，中心 x=560，与日期格及标题横条的中心一致 |
| 翻角 | 对应水平、垂直锚点之间各保留 24 单位负形缝；曲线控制点只负责曲率，不替代对齐锚点 |

保持宽高比、页角的间隔和日期格的共享外接框。建议至少使用 24 px 显示完整日期细节；16 px 应重点检查页面轮廓与日期标记是否仍清楚。复杂背景可在现有净空之外继续增加留白。

## 应用图标

分层源位于 [Icon/AppIcon.icon](../Icon/AppIcon.icon)。原生图标与此矢量母版使用同一页面和日期几何；材质、系统圆角与外观适配由 Icon Composer / macOS 生成。独立 SVG 本身不含这些系统效果。

[课程卡片母版](concepts-v2/course-stack.svg) 保留完整 1024 坐标，便于继续对齐检查与编辑。
