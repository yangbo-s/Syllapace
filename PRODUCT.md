# Syllapace
<!-- impeccable:product-schema 1 -->
## Platform
Local macOS application with native SwiftUI/AppKit chrome and a bundled WebKit workspace. No Windows target.
## Stack
User-confirmed SwiftUI shell + WKWebView hosting React, Tailwind, shadcn, and MIT ReUI components. Swift services own persistence, files, Keychain, Canvas, model calls, EventKit, and Sparkle. Swift Package plus Vite build, Apple Silicon, macOS 26+. Node is a build dependency, not an application runtime.
## Users
Canvas-using students running their own local open-source client.
## Product Purpose
Turn selected-semester materials into an orderly set of class meetings, submission deadlines, and assessments. AI does the filtering and organization; routine valid results do not require manual approval.
## Operating Context
Users configure their Canvas token and BYOK model directly. Local storage and Keychain; no Syllapace backend. The native sidebar offers separate List, Timeline, and Calendar pages over one library; a native desktop card shows upcoming classes and deadlines. Automatic course-material organization is enabled by default once a model and key are configured, can incur provider charges, and can be disabled in Models settings. Importing with Use AI off persists a local-only choice that survives source refreshes; explicitly organizing that material does not opt it into future automatic uploads.
## Capabilities and Constraints
Canvas course/term selection and native source discovery; file/text/public-link import including PDF, DOCX, XLSX, and CSV; evidence-validated BYOK curation; bounded weekly class expansion; source-linked unresolved information; reversible reorganization; date-derived Not started, In progress, and Historical phases, with historical events hidden by default and undated events left explicit. Submission and legacy progress never determine schedule phase; completion controls and overdue warnings are absent. Timeline opens on a full month: classes and assessments are points, and deadlines span only an explicit release date to the due date. Missing release dates remain unknown; legacy personal plans never supply that duration. Calendar opens in month view. Date-only civil dates keep their source day across display timezones. Practice exams are excluded from actual assessments, and midterm reports remain deliverables. Academic calendars are an explicitly selected layer, not default course clutter. Manual edits/rejections, local EventKit ownership, and ICS export remain protected. Private Google authorization, OCR, complete Gradescope/Piazza ingestion, and WidgetKit rollout remain outside this release.
## Brand Commitments
Quiet, exact, compact academic desk with readable spacing and SF system typography. Keep native window, sidebar, toolbar, menus, settings, and desktop interactions. Reuse ReUI components and their design system in the workspace; adapt real data and semantic tokens instead of redrawing the components. Borrow Still Today's desktop card interaction. The approved system revision keeps native navigation authoritative, removes duplicate web headings, counts, view tabs and status strips, and keeps history, search and type controls compact. Routine import and curation feedback lives in toolbar Activity with brief summaries and an on-demand native detail popover; progress, Stop and available undo actions stay accessible without persistent bottom notices. Blocking errors retain native alerts. Appearance offers Follow system, Light and Dark, a custom accent, and 90% / 100% / 115% content sizing shared by native and WebKit workspace content. Direct code-led implementation and real bilingual light/dark window review are user-approved; no separate approved visual comp exists. The Codex, Slack, and Linear references guide the precise course-page/date logo; its explicit alignment and spacing geometry remains unchanged.
