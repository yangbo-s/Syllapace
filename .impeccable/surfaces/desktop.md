## Current workspace

The native sidebar owns separate List, Timeline and Calendar destinations, semester selection and course filtering. Sources and a nonempty review queue remain native destinations. The first viewport contains one title context, compact history/search/type tools and the selected data view; it has no duplicate heading/count, web view tabs, Board, status strip or seven-day ribbon.

List gives spare width to event titles; course/date/status/actions begin at 96/160/108/40 logical pixels. Timeline opens to a full month with a course/event tree, point classes and assessments, and explicit-release-to-due deadline spans. Missing release is unknown, and legacy personal plans cannot create a duration. Calendar opens in month view. All views use date-derived phase and initially hide historical events; no completion or overdue UI is present.

Main initial size is 1120 × 760; minimum content is 940 × 620 before scale. Shared main content sizing is 90%, 100% or 115%, including native and embedded WebKit content; Settings is 640 × 560 before that scale. Follow system / Light / Dark and custom accent changes affect both renderers. Semantic colors and contrast-adjusted custom accent variants are defined by AppAppearance.swift, not by screenshot samples.

Routine feedback occupies toolbar Activity, not schedule height. Notices show a single-line summary for six seconds before becoming an information icon; curation retains progress and its summary. A click opens the native details popover with selectable text, Stop or available undo/dismissal actions. It never auto-opens; blocking errors retain native alerts, and foreground work does not send system notifications.
