# Syllapace 0.5.0

A single Mac workspace for your schedule, with quieter controls and date-based status.

- List, Timeline and Calendar now have separate native sidebar entries. The board, duplicate web heading/tabs, event count and completion filter strip are removed.
- Settings → Appearance offers System/Light/Dark, a custom accent and 90%/100%/115% interface size. Native and WebKit surfaces share semantic colors, course colors and scale.
- Events automatically move from Not started to In progress to Historical. History is hidden by default and can be revealed with the history button. There are no overdue labels or completion controls; Canvas submission state does not decide schedule status.
- Calendar opens to the month. Timeline opens to a full month, using points for classes/exams and verified release-to-due intervals for tasks. Missing release dates remain unknown; old personal plans are not treated as source availability.
- Practice exams no longer become formal assessments. Existing generated practice records are excluded reversibly, with source material and user edits preserved. Date-only values keep their original civil dates.
- Import and organization feedback moves out of the bottom bar: a brief toolbar summary collapses to an activity icon, with full messages and undo actions in an on-demand native popover.
- List titles use the available space, course codes are compact, and search/type controls sit in the view toolbar.

中文：列表、时间线、日历拆为三个侧栏入口；移除看板、重复标题、完成筛选和逾期概念。状态只按日期自动显示未开始／进行中／历史，历史默认隐藏。月历和时间线默认月视图；作业有明确 release 才画时间段，课程与考试画时间点。外观设置支持主题、强调色与整体大小，原生界面和 WebKit 同步。修正练习期中考试被当成正式考试等日期呈现问题，来源资料与人工编辑保留。

Version **0.5.0, build 7**. Library schema 4 and the Sparkle signing identity are unchanged. Use **Syllapace → Check for Updates…** in your existing installation; this release does not replace your installed copy during development verification.

Requires **Apple Silicon and macOS 26+**. The ZIP is the Ed25519-signed Sparkle update archive; the DMG supports manual installation. `SHA256SUMS` contains checksums. The app remains **ad hoc signed and not notarized by Apple**; see [Apple's per-app opening instructions](https://support.apple.com/en-us/102445) if a first launch is blocked.
