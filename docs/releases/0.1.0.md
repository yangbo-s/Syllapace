# Syllapace 0.1.0

Syllapace 的首个 macOS 安装包：把课程大纲、Canvas 作业和人工确认的日期放进一个本地学业日程。

- 原生 SwiftUI 界面，简体中文 / English / 跟随系统；Canvas、OpenAI、API、ICS 等名称保持原文。
- 导入文本型 PDF、DOCX、TXT、Markdown 和 HTML，对照原文审核日期，跟踪再次导入后的变更。
- 自行配置 Canvas token 和可选 BYOK 模型；凭据保存在 macOS Keychain。
- Today、时间线、审核、来源、桌面卡片，以及 EventKit 本地 Apple Calendar 同步和 ICS 导出。
- 从 GitHub Release 检查更新，使用 Sparkle 验证更新包签名并完成安装。

## 安装

需要 **Apple Silicon Mac 和 macOS 26 或更新版本**。下载 `Syllapace-0.1.0-macOS-arm64.dmg`，打开后把 Syllapace 拖到 Applications，再从 Applications 启动。ZIP 是相同应用的压缩版本，也用于应用内更新；`SHA256SUMS` 提供附件校验值。

此包采用 **ad hoc 签名，尚无 Apple Developer ID 签名或公证**。首次打开可能被 macOS 拦截。确认来自本仓库且文件校验一致后，可按 [Apple 官方说明](https://support.apple.com/en-us/102445) 在尝试打开后前往「系统设置 → 隐私与安全性 → 仍要打开」。不要关闭系统安全保护。

## 当前边界

这是可供试用的首发版本。真实 Canvas 账户、模型服务与授权后的 EventKit 日历写入尚未完成端到端联调。提取结果需要人工审核；规则提取主要针对英文大纲，切换界面语言不会翻译原文或改变日期解析能力。扫描 PDF 需要先在其他工具中 OCR。应用未运行时不会后台同步。

First macOS release of Syllapace: a local academic timeline for syllabus dates, Canvas assignments, and reviewed changes.

- Native SwiftUI interface in Simplified Chinese or English, with a system-language option and original product/API names.
- Text-based PDF, DOCX, TXT, Markdown, and HTML imports; evidence-based date review and change tracking.
- Your own Canvas token and optional model API key, stored in macOS Keychain.
- Timeline, review queue, source reader, desktop card, local Apple Calendar integration through EventKit, and ICS export.
- GitHub-hosted updates downloaded, signature-verified, and installed through Sparkle.

Requires **Apple Silicon and macOS 26+**. Open the DMG, drag Syllapace to Applications, and launch it there. The ZIP contains the same app and is used for in-app updates. `SHA256SUMS` covers the release assets.

This build is **ad hoc signed and not Apple Developer ID signed or notarized**. If macOS blocks first launch, consult [Apple's documented per-app opening process](https://support.apple.com/en-us/102445) after verifying the download source and checksum. Keep system security protections enabled.

Live Canvas, model-provider, and authorized EventKit end-to-end checks remain outstanding. Review extracted dates before approving them. Rule extraction mainly targets English syllabi; interface language does not translate source material or expand parsing capabilities. Scanned PDFs need external OCR. Sync runs only while the app is open.
