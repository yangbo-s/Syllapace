# Syllapace 0.1.1

- Added automatic renewal of the saved Canvas personal access token, enabled by default. While Syllapace is open, it checks expiry and requests an extension near the end of the token's lifetime when permitted by the institution. The token value and permissions stay unchanged. Canvas settings shows the expiry or a recovery message and lets you turn renewal off.
- Fixed empty states in Today, Timeline, Review, and search results so they center within the remaining content area at different window sizes.
- Added English and Simplified Chinese renewal messages, plus coverage for expiry boundaries, failures, cancellation, and empty-state layout.

Existing installations can update through **Syllapace → Check for Updates…**. Automatic checks are enabled by default and run roughly every 24 hours while the app is open; installation requires confirmation.

Requires **Apple Silicon and macOS 26+**. The DMG is for manual installation; the ZIP is also the signed Sparkle update archive. `SHA256SUMS` covers the release assets. The app remains **ad hoc signed and not Apple notarized**; for first-launch issues, follow [Apple's per-app opening instructions](https://support.apple.com/en-us/102445).

Live institutional token renewal has not yet been verified. Expired tokens and institutions that refuse renewal still require manual replacement. Automated validation: 69 tests, 9 application self-checks, and 36 reviewed English/Chinese light/dark window captures for the affected interface.

- 新增 Canvas token 自动续期，默认开启。应用运行时检查有效期，并在临近到期时向学校请求延期；原 token 的值与权限不变。Canvas 设置显示有效期或处理提示，也可关闭续期。
- 修复今天、时间线、待审核及搜索无结果页面的空状态偏左，使其在不同窗口尺寸下居中显示于剩余内容区域。
- 补充中英文续期提示，以及有效期边界、失败、取消和空状态布局验证。

现有安装可通过 **Syllapace → 检查更新…** 升级。自动检查默认开启，应用运行时约每 24 小时检查一次，安装由你确认。

需要 **Apple Silicon 和 macOS 26+**。DMG 用于手动安装，ZIP 同时用于 Sparkle 签名更新；`SHA256SUMS` 提供校验值。应用仍为 **ad hoc 签名，尚未经过 Apple 公证**；首次启动遇到系统拦截时，按 [Apple 的单应用打开说明](https://support.apple.com/en-us/102445) 处理。

学校实例的真实 token 续期尚未验证；已过期或学校拒绝续期时仍需手动替换。自动化验证包括 69 项测试、9 项应用自测，以及受影响界面的 36 张中英文浅深色窗口阅图。
