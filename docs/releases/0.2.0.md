# Syllapace 0.2.0

Choose the semester and courses you want to follow before syncing their content. This release expands Canvas source coverage and fixes token identification, model compatibility, and Keychain responsiveness.

- **Semester and course selection.** First sync discovers course metadata, then asks you to select courses and confirm **Save & sync**. The same selection applies to Today, Timeline, Review, Sources, search, the desktop card, ICS export, and new EventKit writes. Optional Portal and other course spaces can be included. Switching semesters preserves history and existing Calendar events.
- **More Canvas sources.** Sync Announcements, Modules, the course front page, referenced Pages, inline syllabus, and attachment references alongside Assignments and Calendar events. Preserve schedule links and continue with accessible resources when a Files directory is unavailable.
- **Clearer academic items.** Distinguish class sessions, assignments, projects, quizzes, exams, and presentations. Associate native Quiz and Assignment IDs to avoid duplicates; retain explicit end times, locations, submission state, and available grades. Source date changes remain reviewable.
- **Explicit external imports.** Import public documents and Google Sheets exports from discovered links. Sources requiring another sign-in retain their browser link. Canvas credentials are never sent with these public-document requests.
- **Connection fixes.** Match additional Canvas token-mask formats while refusing ambiguous identities, and distinguish identification failures from denied or unconfirmed extensions. Reasoning-model requests use compatible completion-budget parameters and omit unsupported sampling controls. Keychain operations no longer block the interface while waiting for system authorization.
- **Existing libraries.** Read schema-1 archives and migrate to schema 2 on the next successful save, keeping the previous file as a backup. An upgraded library requires a Canvas course selection before content sync resumes. Older app versions cannot read schema 2.

Existing installations can use **Syllapace → Check for Updates…**. Automatic checks run roughly every 24 hours while the app is open; installation requires confirmation. This release uses **build 3** and the existing Sparkle update-signing identity.

Requires **Apple Silicon and macOS 26+**. The DMG is for manual installation; the ZIP is also the signed Sparkle update archive. `SHA256SUMS` covers the release assets. The app remains **ad hoc signed and not Apple notarized**; for first-launch issues, follow [Apple's per-app opening instructions](https://support.apple.com/en-us/102445).

Canvas permissions remain institution- and course-specific. A PAT expiry extension must be accepted by the institution; metadata access or a supported mask does not establish that a real extension succeeded. Private Google authorization, Piazza post retrieval, full Gradescope synchronization, and New Quizzes question content are not included. Gradescope information is limited to what is available in Canvas, which may omit individual extensions. See [acceptance evidence](https://github.com/yangbo-s/Syllapace/blob/main/docs/ACCEPTANCE.md) for validation results and outstanding live checks.

先选择想看的学期和课程，再同步其中的内容。本版扩展 Canvas 来源覆盖，并修复 token 识别、模型兼容性和 Keychain 授权时的界面卡顿。

- **学期与课程选择。** 首次同步先获取课程元数据，再由你勾选课程并确认 **保存并同步**。今天、时间线、待审核、来源、搜索、桌面卡片、ICS 导出和 EventKit 新增写入使用相同范围。Portal 等课程空间可按需加入，切换学期保留历史资料和已有 Calendar 日程。
- **更多 Canvas 来源。** 在 Assignments 和 Calendar 之外，同步 Announcements、Modules、课程首页、被引用的 Pages、内联 syllabus 和附件引用。保留 schedule 链接，Files 目录不可访问时继续获取其他可用资源。
- **区分学业事项。** 分开显示上课、作业、Project、Quiz、Exam 和 Presentation。按原生 ID 关联 Quiz 与 Assignment，避免重复；保留明确的结束时间、地点、提交状态和可见成绩。来源改期仍需审核。
- **主动导入外链。** 从发现的链接导入公开文档和 Google Sheets 导出内容。需要其他登录的来源保留浏览器入口；公开文档请求不会携带 Canvas 凭据。
- **连接修复。** 兼容更多 Canvas token 掩码格式，同时拒绝无法唯一确认的身份，并区分无法识别、延期被拒绝或未获确认。Reasoning 模型使用兼容的 completion 上限参数，省略不支持的采样参数。Keychain 等待系统授权时不再阻塞界面。
- **旧资料库迁移。** 读取 schema 1 归档，在下一次成功保存时迁移为 schema 2，并将上一份文件保留为备份。升级后需先确认 Canvas 课程范围，再恢复正文同步；旧版本应用无法读取 schema 2。

现有安装可使用 **Syllapace → 检查更新…** 升级。应用运行时约每 24 小时自动检查一次，安装由你确认。本版为 **build 3**，沿用已有 Sparkle 更新签名身份。

需要 **Apple Silicon 和 macOS 26+**。DMG 用于手动安装，ZIP 同时用于 Sparkle 签名更新；`SHA256SUMS` 提供校验值。应用仍为 **ad hoc 签名，尚未经过 Apple 公证**；首次启动遇到系统拦截时，按 [Apple 的单应用打开说明](https://support.apple.com/en-us/102445) 处理。

Canvas 权限取决于学校及具体课程。PAT 延期必须获得学校接受，能读取元数据或识别掩码不代表已经成功完成真实延期。当前未接入私有 Google 授权、Piazza 帖子、完整 Gradescope 同步或 New Quizzes 题目内容。Gradescope 仅使用 Canvas 实际提供的信息，可能不含个人延期。验证结果和待完成的真实环境检查见[验收证据](https://github.com/yangbo-s/Syllapace/blob/main/docs/ACCEPTANCE.md)。
