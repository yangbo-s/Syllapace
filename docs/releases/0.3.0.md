# Syllapace 0.3.0

Bring documents, text, links, and academic calendars into one reviewed semester timeline. This release adds provider-based model selection, course display preferences, and a more useful desktop card while keeping the app native and local.

- **One material workflow.** Import up to ten files, paste text, or open a public link. Choose a course or academic calendar, year, and time zone; optionally add instructions for your selected AI model. Preview source evidence, edit candidates, and select what to add. Save materials without dates when useful, and undo the latest import without discarding later edits.
- **Spreadsheet support.** Read XLSX and CSV alongside text-based PDF, DOCX, Markdown, HTML, and text. XLSX reads stored values and formula results without evaluating formulas or following external spreadsheet links.
- **Academic calendars.** Add an ICS subscription or import a calendar document, scoped by semester and date range. The CMU preset includes the official feed and a route to the 2026–2027 PDF. Academic milestones and holidays remain separate from classes and assignments. Supported ICS recurrence rules expand within the chosen range; unsupported rules produce warnings. Explicit multi-day all-day ranges carry through to EventKit and ICS export.
- **Choose models from the provider.** Select OpenAI, Anthropic · Claude, DeepSeek, or a custom HTTPS service; load and search available models using your own API key. Anthropic uses its native Messages API with a JSON schema. A manual model-identifier fallback remains available for services without a model list. Keys stay in macOS Keychain, and changing a connection cancels its outdated list request.
- **School and course preferences.** Find your Canvas address through Instructure’s anonymous school directory or enter it manually. Choose course code, course name, both, or a custom label, with per-course overrides from the sidebar.
- **Desktop card.** See the next class and next deadline separately, expand to the next seven days, and choose position lock, screen-edge snapping, or pinning above windows. The card respects the selected semester and courses. This release ships the AppKit desktop panel; a WidgetKit gallery extension is deferred.

The interface supports English and Simplified Chinese. Canvas course selection, evidence checks, local Apple Calendar ownership, and explicit approval before publishing dates remain in place. Model requests happen only when you ask to parse material; public document, academic-calendar, and school-directory requests carry no Canvas token or model key.

## Updating

This release is **0.3.0, build 4**. Existing installations can use **Syllapace → Check for Updates…**. Automatic checks run roughly every 24 hours while the app is open; installation requires confirmation. The update feed uses the existing Sparkle signing identity.

Schema-1 and schema-2 libraries are read and migrated to **schema 3** on the next successful save, preserving a one-time `archive.json.schema-<old-version>.backup` in addition to the rolling backup. Older app versions cannot read schema 3. Keep the backup if you may need to downgrade.

Requires **Apple Silicon and macOS 26+**. The DMG is for manual installation; the ZIP is the Sparkle update archive. `SHA256SUMS` provides asset checksums. The app remains **ad hoc signed and not notarized by Apple**. For a first-launch block, follow [Apple’s per-app opening instructions](https://support.apple.com/en-us/102445).

## Limits

A public academic feed may include only upcoming dates; check its campus/program coverage and use a full-year document when needed. Holidays do not automatically cancel course sessions, and recurring class schedules written in prose are not automatically expanded. Model-list access does not prove every listed model supports extraction on the account. Scanned PDFs require external OCR. Private Google authorization, complete Gradescope/Piazza connectors, OAuth setup, and an unattended background agent are not included.
