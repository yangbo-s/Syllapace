# Syllapace 0.5.2

课程导入现在会使用 Canvas 的结构化日期、公告发布时间和已匹配的官方课表。CMU Pittsburgh 课程按学期与 section 核对每周时间，并根据官方教学日历避开停课日；课表保存在本地，离线仍可查看。

- 同一次课程的多个来源合并显示，保留来源及手动修改。列表、时间线、日历和导出使用一致结果。
- 修复带点 AM/PM、英文日月日期及 release 时间校验；旧记录只补结束时间时不再要求处理冲突。
- 公告中的相对日期使用发布时间，不使用导入时间。已知 Canvas 截止日期和课程提纲不再重复要求补充。
- 处理失败单独显示并可重试；资料未变化时复用本地整理结果。

官方检索当前覆盖 CMU Pittsburgh 的常规完整学期课程。其他学校、无法确定的 section 或未公开的时间继续保留原来源与待确认问题，不借用其他学期的课表。

Apple Silicon，macOS 26.0+。应用目前使用 ad hoc 签名，尚未进行 Apple Developer ID 签名或公证。若首次打开被系统拦截，可按 [Apple 的单应用打开流程](https://support.apple.com/en-us/102445) 操作。
