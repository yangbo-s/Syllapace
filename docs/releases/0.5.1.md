# Syllapace 0.5.1

- 整理缓存按实际正文保存；升级沿用旧结果，失败原因也会保存。资料未变化时不反复请求模型；可在“来源 → 整理”手动重试。
- 列表默认每页 20 项，可切换 50、100 或显示全部；支持“全部日程／本周和下周”。页脚固定可见，使用系统滚动，移除表头拖拽分隔线。
- 重复课程在列表合为一行，可查看每次日期；时间线共用分组，每次课程显示为同一行上的时间点。跨来源的相同课次合并显示，保留原始记录和用户修改。
- 时间线保留月尺度，支持横向滚动和拖动日期表头跨月浏览。“历史”使用文字入口，默认隐藏。
- 从明确的 syllabus 周课表生成有学期边界的课程；同步时自动读取 Canvas 上可访问的 syllabus 文件，并按文件版本缓存。未明确给出的日期仍需补充。

Apple Silicon，macOS 26 或更新版本。安装包使用 ad hoc 签名，尚未经过 Apple 公证；首次打开请遵循 [Apple 的单应用打开流程](https://support.apple.com/en-us/102445)。已有安装可在设置中检查更新。
