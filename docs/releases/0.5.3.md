# Syllapace 0.5.3

改进课程资料整理的日期证据与跨来源合并，并修复时间线课程名称和时间点、时间条的行对齐。

- 正确组合 syllabus 表格中的月份、日、星期与作业条目，保留明确截止时间的秒数；不再因表格换行漏掉可验证的作业日期。
- 同一作业优先采用 Canvas 当前有效截止时间，合并重复来源并保留证据。两份 syllabus 的日期确实矛盾时，只显示一项来源冲突供确认。
- 官方周课表可根据明确的 syllabus 时段识别 Lecture / Recitation，课程取消通知继续作用于对应课次。
- 修复无实际日期变化的旧提案，以及成绩公告被不相关上下文变化触发重复整理的问题。
- 减少“需要补充”页重复计算，纯日期的来源提案不再显示多余的午夜时间。

已用授权的 8 份真实资料验证，并确认再次读取全部命中本地缓存。资料本身缺少可靠时间或日期相互冲突时仍需确认，不会猜测填入。

Apple Silicon，macOS 26.0+。应用目前使用 ad hoc 签名，尚未进行 Apple Developer ID 签名或公证。若首次打开被系统拦截，可按 [Apple 的单应用打开流程](https://support.apple.com/en-us/102445) 操作。
