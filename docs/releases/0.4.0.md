# Syllapace 0.4.0

Syllapace now organizes course materials into a focused workspace instead of asking you to approve every extracted sentence. Classes, submission deadlines, and assessments share four views: **List, Board, Gantt, and Calendar**.

- **AI handles routine organization.** Relevant, evidence-supported dates enter automatically. Grading rubrics, learning objectives, general announcements, and grade-release notices stay out of the schedule. Titles retain meaningful subtypes such as Lecture, Recitation, Project, Midterm, and Quiz. Missing facts and changes that overlap your edits appear in **Needs information**.
- **Changed materials are processed automatically.** With a configured model and key, automatic organization is enabled by default for selected course materials. A source/configuration fingerprint skips unchanged successful work. Reorganization preserves manual edits and rejections, and the latest batch can be undone during the session.
- **Four views, one library.** Use List to scan events, Board to move submission tasks between To do, In progress, and Done, Gantt to plan around deadlines and assessments, and Calendar for month/week/day schedules. Gantt keeps daily classes out by default; select the class type to include them. Due-soon and overdue indicators remain separate from task progress. Planning a task does not move its source deadline; items without a duration remain milestones.
- **Weekly class schedules.** AI identifies explicitly stated meeting patterns; native code expands them only inside known course/source dates, preserving the course time zone. Missing boundaries or ambiguous times produce a source-linked issue rather than guessed classes. Lecture and Recitation schedules remain distinct.
- **A native shell with a bundled workspace.** SwiftUI still owns the window, sidebar, toolbar, menus, settings, and import/editor sheets. WebKit hosts local React/Tailwind and MIT ReUI components. Files, persistence, Keychain, Canvas, model requests, EventKit, desktop cards, and Sparkle remain native. The installed app needs no Node.js or local web server.
- **Focused semester scope.** Course selection and custom labels carry across views. Academic calendars remain available as a separate sidebar layer and do not appear in the default course workspace.

English and Simplified Chinese, light and dark appearances, local Apple Calendar integration, document/text/public-link import, model discovery, and the desktop card remain available.

## AI behavior and privacy

**Automatic organization is on by default**, including after upgrading with an existing model configuration. Saved materials for selected courses can be sent directly to your configured provider while the app runs; your provider may charge for these requests. Turn off **Settings → Models → Automatically organize course materials** to stop background organization. Explicit **Organize** and **Use AI** imports remain available.

Material imported with **Use AI** off stays excluded from automatic model requests, even after refreshing that source. Explicitly organizing it permits that operation without enabling future automatic uploads. Background changes cannot be overwritten by an older event-editor draft, and a late calendar response cannot reactivate a subscription disabled during sync.

The model receives source text and applicable extraction context, not your Canvas token, and has no tools. Native validation checks evidence and dates, but it cannot guarantee perfect semantic interpretation. You can open sources, edit events, and undo the latest reorganization. The embedded web workspace never receives model keys or Canvas tokens.

## Updating

This release is **0.4.0, build 5**. Use **Syllapace → Check for Updates…** in an existing installation. Automatic checks run roughly every 24 hours while the app is open; installation requires confirmation. The existing Sparkle update-signing identity is retained. Publishing a release does not immediately push an update to every running client.

Schema-1 through schema-3 libraries migrate to **schema 4** on the next successful save, preserving a one-time `archive.json.schema-<old-version>.backup` and the rolling backup. Existing completion state is retained; schema 4 adds task progress, planned starts, and curation records. Older versions cannot read schema 4, so keep the backup if you might downgrade.

Requires **Apple Silicon and macOS 26+**. The DMG is for manual installation; the ZIP is the Sparkle archive, with asset checksums in `SHA256SUMS`. The app remains **ad hoc signed and not notarized by Apple**. For a first-launch block, follow [Apple’s per-app opening instructions](https://support.apple.com/en-us/102445).

## Limits

Only explicit recurring weekdays, times, and date bounds are expanded; a semester label alone does not establish the first and last class. Holidays do not automatically cancel meetings. AI may miss or misinterpret material; unresolved information does not become an invented event.

Scanned PDFs still require external OCR. Private Google authorization, complete Gradescope/Piazza connectors, New Quizzes question content, OAuth setup, a WidgetKit gallery extension, and an unattended background agent are not included. Institution permissions and provider compatibility remain account-specific. This release does not claim that every school, model, or real Calendar account has been retested.
