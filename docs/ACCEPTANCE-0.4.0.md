## 已执行的真实模型验证

临时 `SyllapaceCurationProbe` 经用户允许读取一次已保存模型 key，只向配置的 provider 发送虚构课程资料，没有发送真实课程资料或 Canvas token。得到 **9 次课程活动、1 个作业截止、1 次期中考试、0 个问题**；Lecture 与 Recitation 独立，作业发布时间未混作截止，评分说明及成绩发布未进入日程。虚构作业 11 月 12 日 23:59（America/New_York）保留为正确的 UTC 瞬间。

证据：`build/verification/0.4.0/live-curation.log`。临时源码和程序已删除，日志只含虚构课程结果。一次合成资料通过不等于所有课程资料、模型和学校实例的语义准确率已测量；未向真实课程库应用整理。

## 验证中修复的问题

- WKWebView 的 `file://` 不能按原产物的 module/CORS 请求加载资源。改为 classic IIFE + defer，并去除本地 JS/CSS 的 crossorigin；严格 CSP 保持不变。以实际 React 渲染 ACK 验证，不能只看构建成功。
- 不完整模型结果不能据“未返回”删除已有有效日期；部分问题只合并确定结果，并留下来源级问题。
- 全批旧快照撤销会覆盖模型等待期间用户新建的内容。改为每次提交记录稀疏差异，反向恢复，后续编辑优先。
- 用户改标题后来源改期，旧 ID 和新标题可能失去对应。增加兼容的 `sourceTitle`；旧记录仅通过原 ID 哈希证明恢复身份，不做课程级模糊合并。回归要求始终只有一条任务，并保留用户字段与来源的新日期提案。
- 新冲突候选不能标记成“此前已批准”；同一段证据中的多次同名 Quiz 必须保持独立。
- 夏令时切换周的日历时间刻度需按本地钟表时间计算，不能把距午夜经过的分钟数当作整周的时刻。该问题通过真实截图发现，修复需覆盖春季和秋季切换。
- 关闭 Use AI 的本地导入原先会在弹窗关闭后被自动调度再次选中。来源现在持久化 `localOnly`，刷新不清除该选择；显式整理只授权该次操作。实际本地解析/提交/刷新/重载的自测确认自动选择器排除该来源。
- 原生编辑器保存和取消事件采用原记录一致性校验，旧草稿不能覆盖后台已更新的日期、进度和来源观察值。过期校历响应也不能重新开启已禁用的订阅；纯内存 ICS 响应与实际归档回写自测覆盖拒绝及有效提交。

## 明确边界

未在本轮对用户真实课程库执行整理或实际 EventKit 写入；最低 macOS 26 机器、完整 VoiceOver、长时间能耗/内存、自然 Sparkle 调度与本机升级仍未实测。真实 Canvas 课程连接沿用前轮已验证能力，本轮增加的是筛选/整理和投影视图，未声称所有学校 API 已重新联调。课程假期不自动取消课次；未知课程起止不能只靠 “Fall 2026” 推断。

自动整理默认开启；已配置模型时会处理所选课程的已保存资料并产生 provider 请求，设置可关闭，发布说明及双语 README 均已说明。学期与来源切换有过期回复保护。schema 1–3 首次成功保存前保留一次性旧版备份，schema 4 不能直接用旧应用读取。

公开源码只包含 MIT ReUI primitives/examples；未发布付费模板或账户许可证密钥。生产依赖与其许可随应用打包。应用仍为 ad hoc 签名，尚未 Apple 公证。
