## 验证证据

本机证据位于 `build/verification/0.5.0/`，不发布截图中的测试资料库。脚本可重复运行。

- Swift Testing：**223项 / 23套件通过**，见 `tests-final.log`。
- Web：**24项通过**，lint、TypeScript 与离线 Vite 构建通过，见 `web-tests.log`、`web-lint.log`、`web-types.log`。
- 中英文最终构建真实应用自测：**各77项通过**，包括临时本地凭据、归档、导入、修订冲突、独立课程范围、三视图、940×620内容区域内的完整月份、历史隐藏/显示、原生编辑器与强调色回写，还验证导入摘要及展开详情不改变日程 frame，见 `selftest-verified-en.log`、`selftest-verified-zh-Hans.log`。
- 中英文原生全页：`native-final/` 共102张；三视图宽窄/明暗和空状态：`review-fix/` 共36张；消息反馈：`activity-final/` 共20张。完整画面及弹窗已检查，原生编辑器、导入、来源、课程范围和设置未发现新增阻塞。自定义强调色与90/100/115%缩放另有 `appearance-verified/` 16张最终原图。
- 布局检查：102份记录通过，其中48份包含172个探针/区域条目；无探针的系统表单及 WebKit 不能用此检查证明布局正确，另由真实窗口验证。
- 网格 lint 通过。Web 设计检测只运行一次，结果为 `[]`，见 `design-detect.json`；它不验证 SwiftUI，原生部分依赖真实窗口与布局记录。

截图标注的940×620、1120×760均是**内容区域**；完整PNG还包含52pt系统标题栏并以2×像素捕获。缩放检查相应调整内容尺寸，避免把放大的内容硬塞进原窗口。截图使用独立 bundle ID、临时资料库与虚构课程，正式应用保持运行且不被替换。

首轮回归测试证实练习考试会被误分类，后续测试保持原始日期并验证可撤销排除。旧“明确 release 和 due 也应视为歧义”的断言按新需求改为明确日期可识别，同时保留真正多选日期、DST歧义及无效日期的拒绝检查。真实窗口复核发现月轴被容器内在宽度撑开、浅色元数据对比度不足和操作列溢出，均已修正。自定义蓝色经原生合成后的文字对比度最终为浅色5.57:1、深色6.29:1；保留原选择色样，同时为两种外观生成可读变体。独立设计复核针对工作区36张、外观16张、Activity20张原图，原问题闭合；详见本机 `finish-review.md`。直接启动二进制会与运行中的同 bundle 应用干扰，自测脚本改为 LaunchServices 启动独立身份副本；这不修改正式应用。

本轮未使用用户的真实 Canvas 凭据发起同步，不声称覆盖所有课程文档表达方式。缺少明确 release 时保留未知；无效或歧义日期继续走需要补充。没有执行本机下载安装、重启或自然更新计时测试。

## 设计细节

先按 impeccable 重组原生导航和工作区，再按 unslop 检查间距、颜色、图标、文案、字体、布局、细节、内容视觉和动效。保留校园日程工具的安静中性外观；视觉信息来自课程点、月历与真实日期区间，不添加装饰图片。窄月历优先事项标题，溢出列表放在日期旁，时间可在详情查看。无新增入场或循环动画。

方法来源：unslop by Damir Sokolovsky ([heydamir](https://heydamir.design/unslop)), CC BY 4.0；应用界面不复制示例素材。
