# 0.5.1 验收记录

对应 [计划](PLAN-0.5.1.md) R511–R516。用户资料仅用于只读定位；测试使用合成材料和独立资料库，不复制真实课程正文到仓库。

## 诊断证据

- 0.5.0 的缓存指纹与本地规则版本耦合，升级会重新请求；失败只保存在内存。新的正文缓存版本与规则版本分开，兼容旧指纹，失败也持久化，手动整理可明确重试。
- 重复课次来自旧、新来源标题差异（含课程编号和不含编号），以及将每次课当作一行。共享投影去重与系列分组保留原始记录；用户编辑、独立 ICS 系列和不同课程保持独立。
- 时间线固定单月且宽度恰好填满视口，使滚动范围为零。现在保留前后月份缓冲，按窗口计算月宽度；拖动表头及横向滚动都有空间。独立审阅又发现窄窗口裁切：周标题的固有宽度把 479 点视口中的月份撑到约 502 点。轨道改用明确日期宽度，宽度变化重新定位；用户已平移时保留日期锚点。
- 课程资料中存在明确周课表但未生成课程。补充有界的本地 syllabus 识别；链接型 PDF 之前只列入待下载资料，现在自动读取已选课程中有权限的 syllabus 文件并缓存版本。
- 圈出的时钟箭头实际是显示历史，未发现加载旧二进制的证据。已加文字入口。列表从自定义滚动容器改为 WebKit 原生滚动，未反转系统滚动增量。

## 验证

- `./tools/test.sh`：228 项 Swift 测试、24 个 suite 通过。
- Web：30 项行为测试、`npm run lint`、`npm run typecheck` 通过。覆盖分页、全部显示、双周范围、跨来源重复、独立系列、release 保留和 DST 边界。
- `./build.sh --release` 成功；中英文 `./tools/selftest.sh` 各 87 项通过。使用独立 bundle ID、资料库和凭据目录，实际加载随包 React/WKWebView，并检查原生消息回写。
- 真实窗口矩阵为 48 张：中英文 × 浅深色 × 1320/1120/940 点 × 列表/时间线/日历，加空状态、单课程和学校校历筛选。最终原图在 `.impeccable/review/0.5.1-round2/{en,zh-Hans}`；其中 12 张时间线由 `0.5.1-gantt-fix` 重拍替换。独立审阅为 ship，FF-051-01 已关闭，未发现修复引入的实质回归。
- 本地产物在 `build/releases/0.5.1-reviewed`：0.5.1/build 8、arm64、bundle 签名、ZIP 内公钥验证的 Ed25519 更新签名、appcast 约束与 DMG 完整性通过。早期 `build/releases/0.5.1` 候选未用于发布。

回归过程保留了真实失败：正文缓存测试先红后绿；应用测试曾捕获并修复 Swift 独占访问冲突；完整月边界测试先失败再通过。一次主题同步断言在完整重跑前失败，同一构建再次完整运行及中文运行通过，未放宽断言或更改主题实现。一次手工 typecheck 误指向不存在的 `tsconfig.app.json`，已改用项目 `npm run typecheck` 完成检查。

本地日志位于 `build/verification/0.5.1/`：`swift.log`、`web.log`、`selftest-en.log`、`selftest-zh.log`、`month-geometry-red.log`、`build.log`、`package-reviewed.log` 与 `finish-review.md`。这些是本机证据，不随安装包分发。构建仍提示既有 ReUI 源映射、编译器指令和单包体积警告，构建与运行均通过。

## 限制

没有请求真实 Canvas 账户或付费模型。18647 与 19688 的明确周课表模式有覆盖；18794 原资料只有 PDF 链接，须在下一次同步且服务端允许读取后进入资料库，不能宣称该账户课程已全部恢复。本地课表仅识别明确写出的星期、时段和学期边界，不猜缺失日期。物理触控板手势和 VoiceOver 未实测；自动检查验证了实际 WebKit 滚动与合成拖动，未修改系统滚动偏好。

当前仍为 ad hoc 签名，未做 Apple 公证。本机已安装 0.5.0/build 7 留给用户验证应用内更新；没有代用户下载安装或调整更新计时。
