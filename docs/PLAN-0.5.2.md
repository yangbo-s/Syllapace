# 0.5.2 课程证据与每周日程

目标：从已选 Canvas 课程及匹配学校、学期、section 的官方资料生成可用周课表，跨来源合并同一次课程，只向用户呈现需要其判断的问题。保留原生界面、现有模型配置与原始资料。

| 编号 | 行为与验收 | 模块 / 测试 |
| --- | --- | --- |
| R521 | 保留公告发布时间、作业有效截止与开放时间；相对日期有可验证参照，同课程信息可关联 | CanvasClient / CurationContext；模拟 API 与模型输出回归 |
| R522 | 明确英文日期、带点 AM/PM 校验通过；模糊日期及 DST 仍拒绝猜测 | Extraction / EvidenceClock；DateEvidenceRegressionTests |
| R523 | 未手改事件补充结束时间不成为冲突；同一课次多源合并并保留来源，用户修改与独立 section/ICS 保持独立 | Reconciliation / MeetingReconciliation；迁移、重复同步、不同课次回归 |
| R524 | 按学校、课号、学期、section 检索官方课表，按官方上课日期生成每周课程，保留 URL 与证据 | OfficialCourseSchedule；公开源实读、错误学期/section/校区及课程四门验收 |
| R525 | 超时与下载失败归入处理状态；已有结构化日期不重复报缺日期，课程提纲不逐条要求日历日期 | Curation issue policy / native review；缓存与界面自测 |
| R526 | 隔离资料库完成真实课程链路审计、合成回归、应用检查；0.5.2/build 9 发布并公开回读 | Kit tests / audit / selftest / release |

输入：用户已选 Canvas 课程与现有 token、正文及结构化日期、所配模型；公开检索只发送课号与学期，不发送 token/私人资料。输出：来源可追溯的会议、任务和问题；新元数据为可选字段，旧 archive 可解码。不自动覆盖本机安装、凭据或用户日程，现场验证使用隔离副本。

方案：先直接取得可验证的学校官方课表，再将课程相关证据供模型使用；官方结构化周课表不依赖模型生成日期。当前首先支持已验证的 CMU Pittsburgh 官方入口，其他学校保留 Canvas/导入路径，不把搜索摘要或其他学期课表当作事实。与无界浏览代理相比，这一实现不需要新增检索密钥、能固定学期和 section 并回归验证。发布后需要更多学校时按同一来源契约扩展适配器。

顺序：日期/冲突红绿回归 → Canvas 上下文 → 官方检索与合并 → 问题分类 → 四门课程隔离审计 → 构建/界面/发布。每次失败依据具体证据修复后重测，不以隐藏问题或放宽日期证据通过验收。
