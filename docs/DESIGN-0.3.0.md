# 0.3.0 界面实施约定

继承 DESIGN.md 的原生 study-desk 方向；模式 Operate。用户已确认“文件/文字/链接→解析→日程预览→加入”，以及模型选择、课程显示自定义、学校日历和桌面参考方案。直接实现并检查真实窗口，不另开视觉方向竞赛。

- Archetype：现有侧栏主窗口，统一添加资料 sheet（输入与预览同处），紧凑/展开桌面面板。用户已明确将原生 WidgetKit 延后；本版不嵌入扩展。
- Information architecture：今天、时间线、待审核、来源维持；来源入口可添加资料或学校日历。Settings按连接、模型、显示/桌面、Calendar组织，渐进显示高级选项。
- Command map：⌘O 添加资料、⌘N 手动日程、⌘R 同步Canvas、⇧⌘E导出、⇧⌘D桌面卡片、⌘,设置；支持拖入文件和粘贴URL/文字；常用按钮同时有菜单入口。
- Empty states：未设置模型可跳转设置或选择本地规则；资料为空不启用解析；无模型/课程/学校结果分别说明下一步；解析错误保留输入可重试；日历范围无事件显示实际范围，不伪造完整性。
- Feeling：轻松、清楚、可掌控。一个主要完成按钮，原生表单/选择器，四点间距，语义前景色，长文案/名称可滚动或换行，不堆装饰卡片。
- 数据与操作：AI文本永远是候选并带出处。导入按钮明确使用哪个provider，批量操作有Undo；同源凭据保护和机构访问权限不藏在装饰文案里。
- 桌面：借鉴Still Today的内容驱动尺寸、下一个重要事项和摆放细节；继续原生实现，不复用其私有模糊或系统窗口猜测。Reduce Motion时不动画。
- 验证：英文/中文，浅/深色，940×620主窗；新sheet、设置、桌面模式；activity截图、网格、无重复快捷键、保存/撤销/失败恢复。主机安装不变。
