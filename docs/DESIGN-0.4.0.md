# 0.4.0 界面实施约定

本版根据用户确认的 SwiftUI + WebKit 方案，替换主窗口中央工作区，并修正“所有候选交给用户审核”的流程。继承现有品牌、课程颜色与原生系统外壳；中央工作区采用实际安装的 MIT ReUI 组件，不把付费模板源代码放进公开仓库。完整需求和模块边界见 [PLAN-0.4.0.md](PLAN-0.4.0.md)。本文件描述实现约定，不代替实际验收记录。

## 信息组织

对应 REQ-0401、REQ-0402、REQ-0403。默认只显示课程安排、提交截止、考试测验；保留 Lecture、Recitation、Lab、Demo、Homework、Project、Midterm、Final 等细分含义。标题简短，课程标签独立显示；评分标准、课程目标、成绩发布与一般通知留在来源，不建立伪日程。

正常流程为“来源 → AI 筛选与整理 → 原生证据/日期校验 → 协调合并 → 工作区”。缺失时间或与用户编辑重叠的变更进入“需要补充”，不再要求逐条批准正常结果。来源可读、事项可编辑、最近一次整理可撤销。每周课程仅在星期、时间与起止范围有依据时展开，假期不自动推导停课。

侧栏保留学期选择、课程筛选及课号/课程名/自定义显示。主入口为工作区、需要补充、来源；旧 Today/Timeline 的重叠入口合并。校历在独立侧栏分组中，选中后才显示为单独层，不混入默认课程工作区。

## 四种视图的共同语义

对应 REQ-0404、REQ-0405。四视图共用原生事件 ID、日期、课程归属及进度，切换视图不复制资料。

| 视图 | ReUI 组件 | 行为 |
| --- | --- | --- |
| List / 列表 | Data Grid | 统一列出课程、事项、时间与进度，支持共享搜索和筛选。 |
| Board / 看板 | Kanban | 提交任务分为待办、进行中、已完成；支持拖动与菜单操作，不给课程安排套任务状态。 |
| Gantt / 甘特图 | Gantt | 默认显示提交任务计划、截止节点和考试，日常课程可通过类型筛选查看；没有来源时长或计划的事项显示为节点，不编造项目周期。 |
| Calendar / 日历 | Event Calendar | 月、周、日时间关系；来源日期保持只读，编辑经原生事项编辑器完成。 |

“即将到期”“已逾期”根据当前时间派生，与待办/进行中/已完成分开。用户设置计划开始时间后，Gantt 可以调整计划起点；来源截止日期不能被拖动计划改写。来源只给日期时保留 date-only，不虚构 23:59 的截止时间。

## 视觉与交互

对应 REQ-0406。复用 ReUI 的组件结构、密度、交互和语义 tokens；不叠加额外卡片层、营销式标题或逐行入场动画。课程颜色必须伴随文字，完成与临期同时有文字/图标提示。表格行、看板卡片和日历事项使用同一事件标题与课程名。

原生部分继续负责窗口、Toolbar、Sidebar、系统菜单、Settings、导入/编辑 sheet 与桌面卡片。主工作区保留一个视图切换区、搜索和必要筛选；空状态给出添加材料或选择学期的动作。无匹配、无提交任务、没有课程资料、需要选学期、正在连接和操作失败分别表达，不用示例事项填充真实空状态。

支持 English / 简体中文与浅/深色。专业产品名保持原文，课程名及证据不翻译。长课程名可截断并保留可识别标签，原文可打开查看。最小主窗为 940×620；看板与较宽时间视图允许有目的的横向滚动，不将文字挤至不可读。

任务状态同时提供菜单操作，不能只有鼠标拖动入口。保留原生快捷键：⌘O 添加材料、⌘N 新建事项、⌘R 同步 Canvas、⇧⌘E 导出、⇧⌘D 桌面卡片、⌘, 设置。不让 WebView 抢走初始焦点或自行打开新的应用内浏览窗口。

## 数据与桥接边界

对应 REQ-0407、IF-0401。WebKit 仅加载随应用签名打包的静态资源，无运行时 Node、本地 HTTP 服务或远程页面。Swift 是唯一持久化来源；React 收到工作区快照，通过有限命令请求原生更改。写入附带事件 ID 与 expectedRevision；失败返回原生状态，不能先在前端“保存成功”却没有写入资料库。

模型 key 和 Canvas token 始终留在原生服务/Keychain。外部链接通过原生验证后交给浏览器，不能导航进拥有原生桥的 WebView。课程名称、标题、证据作为数据传入，不拼接成可执行脚本。

自动整理在模型设置中有明确开关和资料发送说明，默认开启；模型与 key 配置完成后可处理所选课程资料。导入时关闭 Use AI 会持久化 localOnly 标志，自动整理和来源刷新都尊重该选择；显式整理只授权当次，不清除标志。内容/配置/时间范围指纹缓存避免重复调用已成功且未变化的来源。缺失模型时保存资料并提示设置，不制造一批低质量“待审核事项”。

原生编辑器按打开时的完整事件值校验保存；后台同步或整理已改变该事件时，旧草稿不能覆盖新日期、进度或来源信息。校历同步提交时重新核对原订阅配置；同步中禁用或修改的订阅不被旧响应恢复。

## 验证矩阵

对应 TC-0404 至 TC-0407。自动化覆盖跨视图状态、计划/DDL 分离、date-only 与时区、非法桥接命令、版本冲突和导航边界。隔离自测还在真实 WKWebView 中点击四视图、进度和计划控件，核对原生状态、渲染确认与磁盘持久化；使用临时资料库，不模拟 native bridge。原生完整截图模式每种语言 51 张；`APP_SNAPSHOT_WORKSPACE=1` 快模式为 22 张：四视图 × 两种尺寸 × 浅深色共 16 张，再加空列表、单课程筛选及校历层各两张。

只有收到与当前视图、主题、语言、筛选和数据匹配的渲染完成信号后才截图；加载失败和超时必须报错。验收使用活动窗口、隔离副本和虚构数据，不覆盖正式安装，不把浏览器预览或灰化窗口当成 macOS 应用验收。执行结果、未验证项与证据评分见 [ACCEPTANCE-0.4.0.md](ACCEPTANCE-0.4.0.md)。
